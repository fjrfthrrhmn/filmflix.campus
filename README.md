# FilmFlix

Landing page streaming movie ala Netflix — hero banner, trending poster carousel, slot iklan, dan riwayat tonton. 

## Struktur

```
assets/     # poster, banner iklan, background
pages/      # beranda.html
styles/     # global.css + components/
```

## Menjalankan

Buka `pages/beranda.html` langsung di browser. Tidak ada build step.
